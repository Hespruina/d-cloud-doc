# 入服指南

本指南说明服务器升级后的版本兼容情况，以及正版玩家如何开启正版验证、免去每次进服输入密码的麻烦。

## 版本兼容

服务器已升级至 **26.1.2** 版本。如果你暂时无法更新客户端，使用旧版客户端（支持 1.8 – 最新版本）仍可正常加入服务器，无需强制升级。

## 正版验证（`/premium`）

如果你是 **正版（Premium）Minecraft 玩家**，进服后可在主城输入以下指令开启正版验证：

```
/premium
```

开启成功后：

- 系统会将你的账号与正版 UUID 绑定；
- 之后进入服务器将 **不再需要输入密码**，直接使用正版会话进服即可。

::: warning 警告
**非正版（离线 / 破解）玩家请勿使用 `/premium` 指令！**

正版验证要求使用官方账号会话（正版 UUID）登录。非正版玩家一旦开启，会卡在「无效会话（Invalid Session）」错误，导致 **无法进入服务器**。

出现此类问题视为玩家自行操作导致，后果由本人承担，服务器不提供找回 / 解除服务。
:::

## 常见问题

### Q: 离线（非正版）玩家如何进服？

离线玩家请使用原有方式：首次进服用 `/reg <密码> <确认密码>` 注册，之后每次用 `/l <密码>` 登录，不要执行 `/premium`。

### Q: 开启 `/premium` 后还能改回密码登录吗？

正版验证绑定后默认走正版会话登录。如需恢复密码登录，请联系 QQ 群管理员协助处理。

### Q: 忘记密码怎么办？

联系 QQ 管理员，提供 IP 地址等验证信息进行找回。
